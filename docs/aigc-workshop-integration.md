# AIGC 工坊前端集成说明

## 当前落点

AIGC 工坊已经接入 `web/default` 认证区路由 `/image`，入口位于顶部导航栏，统一名称为 `AIGC 工坊`。页面包含三个子模块：

- 图片生成：通过 `/v1/images/generations` 提交 OpenAI 兼容图片生成请求。
- 视频生成：通过 `/v1/video/generations` 提交视频任务，并通过 `/v1/video/generations/{task_id}` 刷新状态。
- 电商套图：在前端维护主图、场景图、细节图、营销横幅四类场景计划，并按场景批量复用图片生成通道。

`/image` 只在新版 default 前端中注册。项目默认主题已切换为 `default`，否则 classic 前端会接管 SPA 入口并显示页面未找到。

`/image`、`/canvas` 和 `/canvas/{canvas_id}` 仍复用登录校验，但进入后使用 AIGC 独立工作区布局，不显示控制台侧边栏、控制台搜索和配置抽屉。AIGC 工作区内部有自己的左侧 Dock：`AIGC工坊`、`无限画布`、`提示词广场`、`音乐创作`、`我的资产`。其中音乐创作保持内测锁定，其余入口均可切换。

`/image` 主工作台按原站创作页复刻，而不是控制台式多栏表单：顶部保留站点级导航；首屏是柔和彩色背景、浮动 Dock、居中的工坊标题、模式胶囊 Tab、生成面板和“我的 / 模板”结果区。资料库、无限画布和提示词广场保留为 Dock 入口，不再抢占 `/image` 主创作区。

## 前端参数边界

模型选择暴露为“模型 + AIGC 绑定分组”，不暴露渠道选择。后端按 AIGC 配置分组读取生产 `abilities` 中启用的模型，并在请求进入渠道分发前注入目标分组，最终仍由 New API 现有模型名、分组、渠道分发规则选择可用渠道。

默认 AIGC 分组绑定如下，可通过系统 Option `AigcWorkshopModelGroups` 覆盖：

```json
{
  "image_groups": ["GPT生图专用", "AzGPT生图", "Gemini"],
  "video_groups": ["即梦"],
  "text_groups": ["GPT PLUS号池", "GPT PRO号池", "CCMAX极速版"]
}
```

其中图片 tab 会过滤出图片类模型，视频 tab 会过滤出视频类模型，电商套图的规划模型会过滤掉生图/视频模型，避免混合分组中的非目标模型出现在错误入口。

图片生成参考 `cdn.aipaiai.cn/image` 的交互方式，前端提供比例与清晰度两级参数：

- 比例：自动、正方形、横屏、竖屏、4:3、3:4、3:2、2:3、4:5、5:4、21:9、自定义。
- 清晰度：1K 标准、2K 高清、4K 超清。
- 前端根据比例与清晰度组合计算最终 `size`，并继续通过 `/api/aigc/images/generations` 转入 OpenAI 兼容图片生成链路。
- 比例选择不是系统原生下拉框，而是专用弹层面板：常用比例以卡片网格展示，自定义分辨率可输入宽高，范围为 256 到 4096 像素；选择自定义后，图片生成和电商套图都会把该宽高作为最终 `size` 提交。

视频生成不向用户提供分辨率选择。分辨率由视频模型名确认，后端会从模型名中的 `480p`、`720p`、`1080p` 识别并返回 `480P`、`720P`、`1080P` 给前端展示；没有标注时显示为模型内置。

视频时长按模型名是否包含固定时长确认：模型名包含 `15s` 时，界面只允许选择条数，按每条固定 15 秒展示，并按运维记录实际提交 `seconds: "1"`，避免固定时长模型被按 15 倍重复计费。模型名没有固定时长时，界面才允许选择 `5s`、`8s`、`10s`、`15s`，所选秒数会作为请求体 `seconds` 提交。

视频“条数”不再透传为上游 `n` 参数，而是在前端拆成多次独立 `/api/aigc/video/generations` 任务提交。这样每条视频都单独创建任务并按当前分组价格预扣。

电商套图不是直接拼接提示词批量生图，而是两段式工作流：

- 先选择文字模型和生图模型，由文字模型根据商品、品牌调性、场景和补充要求生成套图方案。
- 用户可在同一个页面里和文字模型连续多轮沟通，方案会沉淀到可编辑的“方案卡片”。
- 确认后再用生图模型按选中的场景一键创建执行队列；前端会并发提交每个场景，并显示等待中、执行中、已完成或失败。

模型选择只在前端负责选择文字模型、生图模型和视频模型。前端通过内部请求头 `X-AIGC-Group` 提交后端返回的分组，后端会校验该模型确实属于对应 AIGC 配置分组、当前用户可使用该分组、生产 `abilities` 已启用该模型，校验通过后才进入 relay。

## 控件生效状态

当前 `/image` 主创作页按“能点就要有真实行为”的口径整理：

- 图片生成：提示词、参考素材上传、素材缩略图复用、比例面板、1K/2K/4K、模型选择、数量滑杆和开始生成均已接入前端状态或生成请求。
- 视频生成：提示词、参考素材上传、视频模型、秒/条、条数和生成视频均已接入请求；参考素材通过 `input_reference` 提交给任务 relay。固定 15 秒模型只显示条数选择，普通模型显示 `5s`、`8s`、`10s`、`15s` 秒数选择。
- 电商套图：基础需求、规划/文字模型、生图模型、比例/自定义分辨率、多轮沟通、方案卡片、场景选择和一键执行队列均已接通；执行不再依赖页面上不存在的“商品名称”隐藏字段，固定 seed 会随每个场景的图片生成请求提交。
- 我的资产：刷新、筛选、全选、批量移除、单个移除、视频状态刷新和素材拖拽复用均已接通资料库接口或会话素材池。
- 固定参数：更多设置里的固定参数已可开启，当前支持固定随机种子 `seed`；该参数只对支持 seed 的上游模型生效，不支持的模型需要关闭后重试。
- 明确未接入：音乐创作保持内测锁定；模板库保留入口但显示待接入；更多设置里的风控保障、公开到广场保持禁用说明，不再展示为可点击但无效果的开关。

## 会话素材池

当前版本支持本地文件上传、拖拽复用和生成结果回流到素材池：

- 上传入口接受图片和视频文件，文件会转换为当前浏览器会话内的 data URL，不写入后端，也不会形成长期服务器存储成本。
- 图片文件超过 8MB 时会在浏览器端用 canvas 压缩为 JPEG 后再进入素材池；本地视频超过 8MB 不做浏览器端转码，会提示用户先压缩后上传。
- 生成成功的图片、视频 URL 会自动进入本次会话素材池，右侧生成结果和资料库素材也可以拖拽复用。
- 素材可拖到提示词、视频参考图输入框、电商基础需求、连续聊天输入框或方案卡片。
- 本地上传素材只适合做当前会话的视觉参考和提示词辅助；真正生成后的素材仍按资料库的 24 小时策略管理。

## 原站对比补齐点

本轮对 `https://cdn.aipaiai.cn/image` 和 `https://cdn.aipaiai.cn/canvas` 的可见页面做了功能对比，当前已补齐或对齐以下产品点：

- AIGC 独立 Dock：原站在创作区内有 `AIGC工坊 / 无限画布 / 提示词广场 / 音乐创作 / 我的资产`，当前 default 前端已同步这种浮动入口结构。
- `/image` 首屏形态：当前已改为原站式居中创作页，包括工坊标题、四个模式 Tab、生成面板、更多设置、预计费用和“我的 / 模板”结果区，避免呈现为控制台侧栏式表单。
- 我的资产：资料库从右侧结果面板提升为独立工作区，仍支持图片/视频筛选、刷新、全选、批量移除和拖拽复用。
- 无限画布：新增 `/canvas` 和 `/canvas/{canvas_id}` 路由，支持新建本地画布、进入画布详情、查看会话素材和生成结果，适合整理当前创作素材。
- 提示词广场：新增本地提示词模板工作区，可搜索常用图片、视频、电商提示词，并一键带回工坊继续编辑。
- 图片生成：已覆盖原站可见的比例面板、模型、1K/2K/4K、数量、参考素材上传/粘贴复用、我的/模板入口语义，并补充自定义分辨率输入。
- 视频生成：已覆盖模型、秒/条、条数和参考素材复用；原站可见的首帧/尾帧、多参考图已先以会话素材池方式支持，后续若要严格按首帧/尾帧字段提交，需要确认具体上游视频接口字段。
- 电商套图：已覆盖生图模型、规划/文字模型、多轮沟通、方案卡片和一键执行队列。原站规划模型的“分组 + 模型”二级选择当前映射为模型下拉，实际渠道仍由后台分发。

## 鉴权边界

当前前端页面使用网页登录态额度模式，不再要求用户在页面内填写 API Key。后端 `/api/aigc/*` 桥接接口由 `UserAuth` 读取当前登录用户，再构造不落库的临时 token 上下文进入项目已有 relay / task relay 链路。

该临时 token 没有真实 API Key，不扣 token 表余额；计费仍走现有 `BillingSession` 的用户钱包/订阅资金源，并使用 AIGC 注入的目标分组计算分组倍率。视频等异步任务仍会强制预扣，失败时沿用现有退款链路。

页面不会直接复刻 `cdn.aipaiai.cn` 的 `/api/image/*` 私有接口，因为这些接口在当前 `new-api` 后端中不存在。当前桥接接口只负责把登录态用户接入已有 `/v1` 分发、计费和任务链路。

## 桥接接口

- `POST /api/aigc/images/generations`：登录态图片生成桥接，内部映射到 `/v1/images/generations`；固定参数开启时可携带 `seed`。
- `POST /api/aigc/chat/completions`：登录态文字模型桥接，内部映射到 `/v1/chat/completions`，用于电商套图方案沟通。
- `GET /api/aigc/models`：返回当前登录用户可用的 AIGC 分类模型列表，包含模型名、绑定分组、展示名称、分组倍率、视频分辨率和固定时长信息。
- `POST /api/aigc/video/generations`：登录态视频生成桥接，内部映射到 `/v1/video/generations`；生产即梦固定 15 秒模型提交 `seconds: "1"`。
- `GET /api/aigc/video/generations/{task_id}`：登录态视频任务查询，按当前用户和任务 ID 查询任务。
- `GET /api/aigc/assets?type=all|image|video&p=1&page_size=36`：AIGC 资料库查询，返回统一图片/视频素材字段，仅返回最近 24 小时内未移除的素材。
- `DELETE /api/aigc/assets/{asset_id}`：从资料库移除单个素材。该操作不删除计费日志或任务记录。
- `POST /api/aigc/assets/batch`：批量资料库操作，当前支持 `{"action":"delete","ids":[...]}`。

## 历史与资料库

当前版本不新增数据库表，优先复用已有数据结构：

- 图片生成：生成成功后，桥接控制器捕获图片响应 URL，并写入当前消费日志的 `Other.aigc_assets`。
- 视频生成：任务本身写入已有 `tasks` 表；桥接控制器在提交成功后把提示词写入 `tasks.properties.input`。

资料库接口会把图片日志和视频任务转换成统一资产对象，供前端右侧“资料库”视图展示。所有生成素材默认只在资料库保留 24 小时，超过 24 小时后自动从资料库查询结果中消失；底层账单日志和任务记录仍保留用于计费审计。

资料库管理能力当前只做临时素材管理：

- 单个移除：`DELETE /api/aigc/assets/{asset_id}`。
- 批量移除：`POST /api/aigc/assets/batch`，请求体为 `{"action":"delete","ids":["..."]}`。
- 下载：前端直接打开素材 URL，由浏览器或上游存储负责下载。
- 收藏：已取消，不再为长期收藏增加额外服务器存储成本。

## Docker 本地验证

官方 `Dockerfile` 会同时构建 default 和 classic 两套前端，并编译 Go 二进制。Docker Desktop 资源过低时，前端构建可能被系统杀掉；本地已验证将 Docker VM 调整为 20 CPU、16 GiB 内存后可完成构建。

如网络下载不稳定，可在构建时显式指定代理和 Go 模块代理：

```bash
docker build --pull=false \
  --build-arg HTTP_PROXY=http://host.docker.internal:7890 \
  --build-arg HTTPS_PROXY=http://host.docker.internal:7890 \
  --build-arg GOPROXY=https://goproxy.cn,direct \
  -t new-api-aigc-local:latest .
```

本地运行示例：

```bash
docker run --rm -d --name new-api-aigc-local \
  -p 13000:3000 \
  -e TZ=Asia/Shanghai \
  new-api-aigc-local:latest --log-dir /data/logs
```

## 后续接口对接点

- 任务历史：当前已支持从 AIGC 资料库接口读取图片日志和视频任务，资料库侧支持移除和批量移除；如果未来需要文件夹、团队共享等能力，再考虑新增专用资产表。
- 参考图上传：当前本地素材池不落库；如果未来要跨会话复用或让上游模型稳定读取私有文件，需要接入对象存储或文件上传接口。
- 电商套图模板：当前内置多类基础场景；如需运营可配置模板，需要增加模板管理接口。
